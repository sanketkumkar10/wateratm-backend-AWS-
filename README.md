# WaterATMBackend

This project contains the backend for the Water ATM application.

## Structure

- `app/api` - API layer
- `app/core` - core app logic and configuration
- `app/database` - database models and session utilities
- `app/models` - domain models
- `app/routers` - route definitions
- `app/schemas` - request/response schemas
- `app/services` - business services
- `app/utils` - utility helpers
- `app/main.py` - FastAPI application entrypoint
# Water ATM Backend AWS

Production backend using FastAPI, PostgreSQL, Razorpay and AWS EC2.
